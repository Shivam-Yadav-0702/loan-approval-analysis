# 💰 Loan Approval Analysis — EDA Project

## 📌 Objective
Analyze loan approval dataset to understand customer demographics,
income patterns and key factors influencing loan approval decisions.

## 📊 Analysis Areas
- Data Cleaning & Missing Value Treatment
- Applicant Income Distribution Analysis
- Loan Amount Outlier Detection
- Loan Approval Status Distribution
- Income vs Loan Amount Relationship
- Education vs Loan Amount Comparison
- Correlation Heatmap & Pairplot Analysis

## 🔍 Key Insights
- Most applicants fall in lower-middle income range with few high-income outliers
- Approved loans outnumber rejections in the dataset
- Higher income applicants generally apply for larger loan amounts
- Graduate applicants tend to apply for slightly higher loan amounts
- Applicant income and loan amount show moderate positive correlation
- Several outliers exist in loan amount — may affect future modeling

## 💡 Recommendations
- Financial institutions should improve risk analysis for outlier applicants
- Detailed credit history analysis can improve approval accuracy
- Additional demographic segmentation can provide better business insights

Loan sanction dataset with applicant demographics,
